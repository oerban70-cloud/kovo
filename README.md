# Kovo

Aplikasi Android untuk nonton V-League Korea di HP.

![Unduhan v3.11](https://img.shields.io/github/downloads/oerban70-cloud/kovo/v3.11/total)

## Download

Download APK terbaru di bawah ini, lalu install di HP Android:

**[Download Kovo v3.11 (APK)](https://github.com/oerban70-cloud/kovo/releases/download/v3.11/Kovo_1.0_v3.11.apk)**

Ukuran: 44.562.896 byte. MD5: `f766e644953cc0f44d2066baa1097496`.

Catatan install: bila Android menolak install APK ini di atas installasi Kovo yang lama, uninstall dulu aplikasi Kovo yang lama, lalu install yang ini.

## Fitur

- **Live** — nonton pertandingan V-League yang sedang berlangsung (VPN Korea sudah built-in di aplikasi).
- **Jadwal** — jadwal pertandingan (Red Sparks, Hillstate, Pink Spiders, IBK Altos, GS Caltex, Hi-Pass, SOOP).
- **Klasemen** — klasemen V-League putra dan putri.
- **Full Match** — replay pertandingan penuh.
- **Pemutar video** — pilihan resolusi Otomatis / 144p / 720p / 1080p, otomatis menyesuaikan jaringan.
- **Stream** — stream kamera / layar HP sendiri ke YouTube (RTMP).

## Statistik unduhan
